Ce projet consiste à développer une solution d’intelligence artificielle dédiée à l’analyse d’images cérébrales, combinant la classification des tumeurs avec TensorFlow/Keras et leur détection et localisation avec YOLOv8. Il intègre également MLflow pour le suivi des expériences, Apache Airflow pour l’orchestration du pipeline, FastAPI pour exposer les modèles via des API REST et Streamlit pour proposer une interface interactive de prédiction.

Contexte du projet
Vous êtes développeur IA junior au sein d’un laboratoire biomédical spécialisé en imagerie médicale. Le laboratoire souhaite développer une solution d’analyse automatisée d’images cérébrales afin d’assister les spécialistes dans l’identification et la localisation des tumeurs cérébrales.

Votre mission consiste à concevoir une solution unifiée basée sur le Deep Learning, intégrant deux approches complémentaires :

La classification d’images cérébrales à l’aide d’un modèle pré-entraîné basé sur GoogLeNet et TensorFlow/Keras.
La détection et la localisation des tumeurs cérébrales à l’aide de YOLOv8.
Vous devrez également mettre en place un système de suivi des expériences, automatiser les étapes du pipeline et exposer les modèles à travers des API REST, consommées par une interface Streamlit.

Classification des tumeurs cérébrales avec TensorFlow/Keras
Importer les bibliothèques nécessaires.
Charger les images du dataset et vérifier leurs extensions (jpeg, jpg, bmp, png). Écarter les fichiers qui ne correspondent pas aux formats autorisés.
Utiliser un bloc try-except pour gérer les erreurs lors du chargement des images.
Explorer les classes du dataset à partir des noms des dossiers.
Représenter le nombre d’échantillons de chaque classe à l’aide d’un countplot.
Afficher un échantillon d’images pour chaque classe.
Diviser les images en trois ensembles : Train, Validation et Test, selon la répartition suivante : 70 % pour l’entraînement, 15 % pour la validation et 15 % pour le test.
Compter les images présentes dans chaque ensemble.
Appliquer des techniques d’augmentation des données, telles que le flou (blur), l’ajout de bruit (noise) et le retournement (flip), uniquement sur les données d’entraînement, afin d’enrichir les échantillons et de réduire les déséquilibres entre les classes.
Utiliser les fonctions de prétraitement de TensorFlow/Keras pour redimensionner les images, les convertir au format adapté au modèle et normaliser les valeurs des pixels.
Utiliser tf.keras.utils.imagedatasetfrom_directory() pour charger les images par lots (batches) et activer le mélange aléatoire (shuffle=True) pour l’ensemble d’entraînement.
Utiliser une implémentation compatible de GoogLeNet pré-entraîné et adapter sa partie de classification (fully connected layer) à la tâche demandée.
Déterminer les hyperparamètres d’entraînement, notamment le taux d’apprentissage (learning rate), la fonction de perte (loss function) et l’optimiseur (optimizer).
Entraîner le modèle en utilisant l’ensemble d’entraînement et suivre ses performances sur l’ensemble de validation.
Évaluer le modèle à l’aide de métriques adaptées, notamment l’accuracy, la précision (precision), le rappel (recall) et le F1-score.
Analyser les résultats à l’aide d’une matrice de confusion et comparer les performances sur les ensembles d’entraînement et de test.
Sauvegarder le modèle entraîné.
